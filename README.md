### AI-assisted engineering

Hermes, Claude Code, and Codex are complementary engineering assistants in my workflow. The working contract is evidence-first:

- Read repository instructions before editing
- Verify the exact checkout and preserve unrelated changes
- Prefer read-only diagnostics and the smallest scoped change
- Keep secrets and generated runtime artifacts out of source control
- Report verification honestly and never weaken safety gates
